# Rekha's Knee Recovery & Rehab Guide (Web App)

A clean, responsive, and patient-friendly web application designed specifically for Rekha to understand her Right Knee MRI results and follow a safe, guided daily rehabilitation exercise program.

## Features
- **MRI Findings Breakdown:**
  - Medial Meniscal Tear (Horizontal, posterior horn, non-extruded / stable)
  - Grade 4 Parapatellar Chondrolysis (Cartilage loss beside the patella)
  - Hoffa's Fat Pad Oedema (Fat pad irritation under the kneecap)
  - Prepatellar Bursitis (Fluid sac in front of the patella)
  - MCL Low-Grade Chronic Sprain (Inner ligament stability intact)
  - Small Joint Effusion (No Baker's cyst)
- **Reassuring "Traffic Light" Overview:** Instantly shows which major structures are completely intact (ACL, PCL, LCL, Tibiofemoral cartilage, Bone marrow) to provide comfort.
- **Dedicated Exercise Program:**
  1. Isometric Quad Sets (Towel press)
  2. Straight Leg Raises (SLR)
  3. Gentle Heel Slides
  4. Side-Lying Clamshells
  5. Bilateral Glute Bridges
  6. Seated Terminal Knee Extensions
- **Instructional Video Links:** Direct one-click access to curated physiotherapist exercise demonstration videos for each movement.
- **Interactive Daily Checklist:** Saves daily progress directly in the browser so she can tick off exercises as she completes them.
- **Specialist Consultation Prep:** Questions ready to ask referring clinician Mr. Stephen Palmer.

## How to Open
Simply double-click `index.html` in your file explorer or open it in any modern browser (Chrome, Edge, Safari, Firefox). It works offline without needing any web server setup.
